# Интерактивное резюме

Интерактивный одностраничное резюме frontend-разработчика, созданное с использованием HTML, CSS и JavaScript.

## Сайт

[GitHub Pages](https://irene-lab80.github.io/CV-vanilla-js/)

## Реализовано

- адаптивная верстка для компьютеров и мобильных устройств;
- раздел навыков с категориями Frontend, Backend и Tools;
- поиск и фильтрация по навыкам;
- поддержка светлой и темной темы;
- сохранение выбранной темы после обновления страницы;

## Технологии

- HTML5;
- CSS3;
- JavaScript;

## Локальный запуск

Скачайте репозиторий и откройте `index.html` в браузере.
